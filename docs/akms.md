# AKMS integration guide

AKMS stands for **Adaptive Knowledge Management System**. It adds a structured, domain-aware knowledge graph layer on top of the documents and notes generated by the research workflow.

## What AKMS is

In AKMS terms, knowledge is organized into a directed graph with two broad layers:

- a **global/domain layer** for concepts, patterns, derivations, and reusable knowledge
- a **repository/local layer** for confidence, pitfalls, task history, and project-specific context

This makes AKMS less like a pile of notes and more like a reusable research memory system.

## The AKMS pieces relevant to Logic-Loom

Logic-Loom touches two AKMS-adjacent capabilities:

### AKMS core

AKMS core provides the graph model and graph build/load routines that Logic-Loom can inspect in read-only form.

In practical terms, that enables:

- filtered graph views
- ego-graph slices around one node
- cluster/tag/domain slices
- node inspection and jump-back actions into related review flows

### AKMS node generation tooling

The `AKMS_nodes_gen` package provides the batch-selection and node-generation workflow used to turn curated source collections into candidate AKMS nodes.

That includes:

- a **Batch Picker** UI for assigning papers to NotebookLM notebooks
- serial or batch extraction workflows
- validation tooling for generated nodes
- promotion flows for moving verified nodes into the vault

## What Logic-Loom currently exposes

When the supporting AKMS resources are available, Logic-Loom may expose:

- **Picker** — batch selection and notebook-oriented paper grouping
- **Nodes** — generated-node browsing, validation, and review
- **Graph** — read-only graph exploration based on AKMS core data

## Important release caveat

AKMS integration is **optional** and release-dependent.

For early public releases, you should assume the following unless the release notes say otherwise:

- AKMS-specific tabs can be gated or unavailable
- a readable AKMS source vault may still be required
- release builds may prioritize core Logic-Loom + zsum flows first, with AKMS features following later

That means the presence of an AKMS tab in the UI is not the same thing as a guarantee that every public alpha ships the full AKMS toolchain.
