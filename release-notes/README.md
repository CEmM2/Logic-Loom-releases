# Release notes

Store one markdown file per release tag in this folder.

Recommended naming:

- `v0.1.0-alpha.1.md`
- `v0.1.0-alpha.2.md`
- `v0.1.0-beta.1.md`

These files serve two purposes:

1. version-controlled release history inside the repo
2. draft body text for GitHub Releases
